# 项目 MVP 进度与 TODO（2026-09-18）

## 1. MVP 当前定义

当前 MVP 不是一个单独的库存看板，而是一条可追溯闭环：

> 真实或明确标记的模拟数据 → 规则研判 → 总部/督导下发 → 门店执行并提交凭证 → 自动重算 → 人工确认 → 关闭、重开或升级。

## 4. 未进入 MVP 或明确后置

- AI 研判：计划作为人工触发的规则交叉验证，不直接写库存或自动关单。
- 经营 KPI：先完成数据契约与 28 营业日模拟器，再展示损耗、可支撑天数和理论物料毛利。
- 加盟商支付与对账：当前不接真实支付，只保留第二阶段方案。
- 正式 OAuth、MFA、验证码和生产密钥体系。
