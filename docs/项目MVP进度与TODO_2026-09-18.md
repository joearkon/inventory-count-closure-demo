# 项目 MVP 进度与 TODO（2026-09-18）

## 1. MVP 当前定义

当前 MVP 不是一个单独的库存看板，而是一条可追溯闭环：

> 真实或明确标记的模拟数据 → 规则研判 → 总部/督导下发 → 门店执行并提交凭证 → 自动重算 → 人工确认 → 关闭、重开或升级。

### 已确认的产品边界

- 系统保留两个入口：加盟商店员、加盟商和区域督导使用移动端；总部运营和总部管理员使用 PC 后台。
- 三端查看的是同一任务/工单，不复制业务记录；差异来自组织范围、角色权限、信息密度和可执行动作。
- 主动运营任务和异常跟进工单可以关联、统一搜索，但来源、状态机和关闭门禁不能混为一类。
- 门店端保留任务、日常运营、对话助手三个底部 Tab；助手保持连续对话，所有库存写入仍需人工确认。
- 没有当前营业日销售回传时，不生成销售额、销量趋势或经营损失结论；页面必须展示营业日、数据截至日和可信状态。
