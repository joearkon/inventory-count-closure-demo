## 需品牌补录的字段

| 字段 | 口径 | 必填性 |
| --- | --- | --- |
| 半成品编码 / 名称 | 唯一标识一种备料 | 必填 |
| 标准投入 | 每批各原料数量及单位 | 必填 |
| 标准产出 | 每批可用成品数量及单位 | 必填 |
| 标准出成率 | 标准产出 / 标准投入 | 必填 |
| 合理损耗率 | 正常制作可容许的损耗上限 | 必填 |
| 保质期 | 小时 / 自然日，并明确起算时点 | 必填 |
| 储存条件 | 常温 / 冷藏 / 冷冻及温度范围 | 必填 |
| 规则版本 / 生效时间 | 用于历史批次与新规则分界 | 必填 |
