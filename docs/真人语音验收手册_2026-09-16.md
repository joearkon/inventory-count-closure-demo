# 门店助手真人语音验收手册

## 前置检查

- Windows 已检测到 `USB Audio Device` 和 Realtek 音频设备，状态均为 `OK`。
- 本机已安装 Google Chrome 和 Microsoft Edge。
- 必须使用 HTTPS 线上地址，并由真人在浏览器中授权麦克风。
- 安静环境、正常语速，麦克风距离约 20–40 cm。

## 测试入口

`/voice-qa/?store=STORE001`

页面中先点击“检查浏览器与麦克风”，然后按顺序朗读 9 条用例。该页只调用门店助手理解接口，不会提交调拨、报损、收货或盘点单。

## 验收口径

1. 中文、English、Bahasa Indonesia 各 3 条：调拨、库存查询、报损。
2. 每条保存转写文本、助手意图、关键词命中和通过状态。
3. 最低验收：每种语言至少 2/3 条意图正确，9 条总体至少 8/9 正确；所有结果不得直接写库存。
4. 完成后点击“导出 JSON 报告”，作为真机验收证据。

## 失败处理

- `not-allowed`：在浏览器地址栏的站点权限中允许麦克风。
- `no-speech`：检查输入设备、音量和环境噪声后重试。
- 浏览器不支持 Web Speech：保留文字输入，第二阶段切换为 `MediaRecorder + 服务端 ASR`。
- `id-ID` 转写稳定性不足：不放宽库存写入规则；ASR 转写仍必须先进入草稿确认。
