# 演示顺序手册（2026-09-16）

## 0. 演示前检查

1. 打开“库存台账”，确认营业日和 STORE001。
2. 打开“盘点计划”，确认 20 项物料中 12 项每日盘点、8 项按需盘点。
3. 打开“库存单据”，确认已有收货、报损、调拨的单号与状态。
4. 打开“库存研判”，确认仅显示 D2、D1、S1、T2 四类。

## 1. 日常盘点

1. 在“盘点计划”生成今日每日计划。
2. 门店端打开今日任务，进入盘点。
3. 上传第 1 张纸质盘点单；确认页面提示已识别项数并要求继续上传。
4. 上传第 2 张；人工确认模糊项后提交。
5. 回到台账，确认“门店实盘”由待执行变为已确认，并显示盘点单号和提交时间。

## 2. 不定期/工单盘点

1. 在“盘点计划”选择 STORE001、物料和来源。
2. 选择“总部临时盘点”或“跟进工单”；工单来源填写工单号。
3. 下发后在列表确认范围、状态和说明。
4. 门店端确认出现同一任务，提交后回到原工单验证。

## 3. 报损与调拨

1. 门店助手输入“黑糖珍珠报损 2kg，过期”；确认草稿后直接提交，照片可选。
2. 在“库存单据”筛选报损单，核对单号、门店、物料、数量和已生效状态。
3. 门店助手输入“调 2kg 黑糖珍珠去 STORE002”。
4. STORE001 提交后状态为待收货；STORE002 确认实际收货后变为已收货。

## 4. 库存研判

1. 查看四类风险卡的首要排查位置。
2. 展开直接证据，核对今日/近 3 日的收货、调拨入、报损、BOM 消耗、期初和实盘。
3. 建立跟进工单；工单可关联定向盘点、收货、报损或调拨单。
4. 验证后标记已完成或排查无异常；不直接定责、不自动改库存。

## 5. 门店助手多语言

1. 语言选 English，说“Transfer 2 kg of brown sugar pearls to STORE002”。
2. 语言选 Bahasa Indonesia，说“Pindahkan 2 kg mutiara gula merah ke STORE002”。
3. 连续两句测试：“我要做调拨到 STORE002” → “黑糖珍珠 2kg”。
4. 所有操作都应先显示确认表单，不可由语音直接写库存。
