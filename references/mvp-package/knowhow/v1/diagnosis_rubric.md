# 5 档研判输出模板 (Diagnosis Rubric)

> 面向加盟商运营诊断与总部管理双轨推送 MVP
> 版本: v1 | 维护方: 飞书/豆包工作侧
> 适用：AI 诊断输出、加盟商诊断报告、总部研判报告

---

## 1. 五档研判输出标准结构

每条异常判定 = **判定档 + 证据 + 建议 + SLA**

```
┌─────────────────────────────────────┐
│  🎯 研判输出（Diagnosis Output）    │
├─────────────────────────────────────┤
│  档位：[有证据 / 已排除 / 疑似 / 证据不足 / 待盘点] │
│  规则：[D2 / D1 / S1 / T2]         │
│  物料类型：[PKG / LIQ / SEMI / WASTE / WEIGHT / GEN] │
│  物料：[物料名称]                  │
│  门店：[门店编码 / 门店名称]        │
│  异常时间：[YYYY-MM-DD]            │
├─────────────────────────────────────┤
│  📊 证据（Evidence）                │
│  • [关键数据 1]                    │
│  • [关键数据 2]                    │
│  • [关键数据 3]                    │
├─────────────────────────────────────┤
│  💡 建议（Recommendation）          │
│  • [操作建议 1]                    │
│  • [操作建议 2]                    │
├─────────────────────────────────────┤
│  ⏰ 响应 SLA：[N 小时]              │
│  🔄 反馈方式：[飞书卡片 / AI助手 / 邮件] │
│  ⬆️ 升级路径：[超时 → ...]         │
└─────────────────────────────────────┘
```

## 2. 五档各自的输出模板

### 2.1 有证据（confirmed）

```
🎯 研判结论：【有证据】D2 负库存异常
📍 涉及门店：STORE001 (小茶日记·Pro店)
📍 涉及物料：黑糖珍珠 (SKU: BS-PEARL-1KG)
📅 异常时间：2026-09-16

📊 证据链：
• 期末库存：-150 g
• 当日销量：23 杯
• 流水中无红冲/冲销记录
• 上次入库：2026-09-14 (入库量 5000g)

💡 建议操作：
1. 立即核查入库单 RK-20260914-001 是否录入正确
2. 检查近 7 日是否有漏减库存
3. 24h 内通过 AI 助手补录或确认

⏰ 响应 SLA：1 小时
🔄 反馈方式：飞书卡片 + AI 助手对话
⬆️ 升级路径：1h 未响应 → 督导现场核查
```

**判断要点**：
- ✅ 证据链 3 项以上
- ✅ 指向具体单据号 / 时间 / 数量
- ✅ 建议可执行（不需要"咨询"）
- ✅ SLA 明确（critical = 1-4h）

### 2.2 已排除（excluded）

```
🎯 研判结论：【已排除】销入比异常
📍 涉及门店：STORE002 (小茶日记·新加坡店)
📍 涉及物料：杯盖 (PKG)
📅 异常时间：2026-09-16

📊 排除原因：
• 销入比 0.25 触发 T-014 阈值
• 实际为新 SKU "秋季限定" 上线 14 天
• 该 SKU 计划性备货 30000 个杯盖
• 14 天销量预计 8000 个，符合爬坡期特征

💡 后续动作：
• 已在新品上线记录中标注
• 14 天后自动重判
• 无需人工介入

📁 已归档至：已排除日志 2026-09-16-007
```

**判断要点**：
- ✅ 解释了"为什么不异常"
- ✅ 引用了具体业务场景（新品上线 / 促销 / 季节）
- ✅ 无需人工介入
- ✅ 归档路径可追溯

### 2.3 疑似（suspect）

```
🎯 研判结论：【疑似】D1 理论与实盘差异
📍 涉及门店：STORE003 (小茶日记·KL店)
📍 涉及物料：半成品奶茶 (SEMI)
📅 异常时间：2026-09-16

📊 当前证据：
• 理论期末：5000g
• 实盘期末：4250g
• 差异：750g (15%)
• 阈值：8%（SEMI 类）

📊 不确定因素：
• 近 3 日有调拨出库 2000g（来自 STORE002）
• 半成品制作周期 4h，可能存在残余未记录
• 配方最近 5 天未变更

💡 建议人工核查：
1. 督导现场查看半成品制作过程
2. 确认调拨出库是否完整
3. 检查是否有半成品报废未记录

⏰ 响应 SLA：24 小时
🔄 反馈方式：飞书消息给督导
⬆️ 升级路径：未复核 → 列入下周复诊
```

**判断要点**：
- ✅ 列出了"已知的"和"不确定的"
- ✅ 建议"核查"而不是"定责"
- ✅ SLA 适中（24h）
- ✅ 升级路径明确

### 2.4 证据不足（insufficient）

```
🎯 研判结论：【证据不足】S1 安全库存预警
📍 涉及门店：STORE004 (小茶日记·雅加达店)
📍 涉及物料：糖浆 (LIQ)
📅 异常时间：2026-09-16

📊 已知信息：
• 期末库存：2000g
• 阈值（T-002）：< 3 天销量
• 7 日销量均值：800g/天
• 当前期末 / 日均：2.5 天

📊 缺失信息：
• ❌ 9 月 16 日当天销量数据未回流
• ❌ 是否有紧急入库计划未确认
• ❌ 是否为节假日销量骤降无法判定

💡 建议补录：
1. 加盟商确认今日销售数据
2. 加盟商确认是否有待入库订单
3. 3 日后重跑判定

⏰ 响应 SLA：无需立即响应（系统自动重跑）
🔄 反馈方式：飞书消息提示
⬆️ 升级路径：3 日后仍未补录 → 升级为疑似
```

**判断要点**：
- ✅ 明确列出"缺什么数据"
- ✅ 补录路径具体
- ✅ 不催促立即响应
- ✅ 重判定时间明确

### 2.5 待盘点（pending_count）

```
🎯 研判结论：【待盘点】D1 理论与实盘差异
📍 涉及门店：STORE005 (小茶日记·巴厘店)
📍 涉及物料：黑糖冻 (WEIGHT)
📅 异常时间：2026-09-16

📊 当前数据：
• 理论期末：1200g
• 实盘数据：最近盘点 2026-09-10（6 天前）
• 差异判定：需新盘点数据

📊 等待触发：
• 下次盘点时间：2026-09-17 (周一)
• 盘点方式：AI 助手引导加盟商盘点

💡 后续动作：
• 加盟商 09-17 完成盘点后自动重判
• 期间继续监控其他指标

📁 已加入盘点队列
```

**判断要点**：
- ✅ 明确"需要什么动作"
- ✅ 时间点具体
- ✅ 期间不打扰
- ✅ 自动重判路径

## 3. 不同角色的研判输出适配

### 3.1 给加盟商看（关怀型）

```
【小茶日记 · 加盟商诊断】
━━━━━━━━━━━━━━━━━━━━
你好！我们发现一个需要你关注的事 👀

🎯 研判结论：【疑似】半成品奶茶损耗偏高
📍 你的门店：小茶日记·Pro店 (STORE001)
📅 检测时间：今天

我们观察到：
• 理论损耗率应该是 8%，但今天实际是 15%
• 比平时多了 7%，可能的原因有几个：
  ⓐ 制作过程有残余没记录
  ⓑ 配方最近有过调整

建议你（24 小时内）：
1. 📱 在 AI 助手回复"半成品配方"，我们帮你对一下配方
2. 📋 检查今天有没有半成品报废
4. 💬 不确定的话，直接在 AI 助手里问我们

需要我帮你做什么吗？回复任何问题都行。

━━━━━━━━━━━━━━━━━━━━
```

**特点**：
- 用"我们"而不是"系统"
- 用"建议"而不是"必须"
- 用 emoji 软化语气
- 提供"AI 助手"作为兜底

## 4. 五档研判的反模式（避免踩坑）

### ❌ 反模式 1：直接定责到人

```
❌ "员工张三偷拿了 500g 黑糖珍珠"
✅ "理论期末与实盘差异 500g，可能原因：员工盘点遗漏 / 称重误差 / 漏记入库"
```

### ❌ 反模式 2：模糊建议

```
❌ "请关注一下"
✅ "建议 24h 内：(1) 在 AI 助手回复"配方核对" (2) 检查今天是否有报废"
```

### ❌ 反模式 3：忽略边缘情况

```
❌ "销入比异常，请核查"
✅ "销入比 0.25 < 阈值 0.3。当前为新 SKU 爬坡期，已自动排除；如非爬坡期请人工核查"
```

### ❌ 反模式 4：缺失 SLA

```
❌ "请尽快处理"
✅ "SLA：1 小时 / 24 小时 / 48 小时（按档位）"
```

### ❌ 反模式 5：过度自动化

```
❌ "已自动扣减加盟商账户 500 元"
✅ "建议加盟商在 AI 助手补录或确认"
```
