## 与 v1 的关系

```
v1 (库存):  5 类物料异常 + 4 棵决策树 + 5 档输出
v2 (新增):  5 大维度门店异常 + 5 个 MVP 场景 + 闭环验证
```

**v1 关注"物料维度"**（库存怎么不对）
**v2 关注"门店维度"**（门店怎么不对）
**两者结合 = 完整归因**：例如"门店销售下滑 + 库存安全库存不足 → 断货是根因"
