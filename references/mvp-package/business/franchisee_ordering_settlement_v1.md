## 2. 价格来源

### 2.1 价格体系设计

| 价格类型 | 定义 | 适用范围 | MVP 状态 |
|---|---|---|---|
| **目录价** | 总部统一定价表（基准） | 所有物料 | ✅ 已有（订货单字段） |
| **促销价** | 临时促销折扣（满减 / 阶梯） | 限物料 / 限周期 | ⚠️ MVP 不启用 |
| **协议价** | 与特定加盟商单独约定的价格 | 大客户 / 战略合作 | ⚠️ MVP 不启用 |
| **调价生效日** | 价格调整需 ≥ 7 天预告 | 全球生效 | 📌 流程约定 |

### 2.2 价格字段（在物料主数据）

| 字段 | 含义 | 来源 | 示例 |
|---|---|---|---|
| 基本单位 | 内部核算单位 | BOM | g / 个 / L |
| 采购单位 | 报价单位 | 总部定价表 | 1 Kg / 1 箱(5000 个) / 1 箱(4000 个) |
| 采购单价 | 1 采购单位的 IDR 报价 | 总部定价表 | 24,300 IDR / Kg |
| 采购换算系数 | 采购单位 / 基本单位 | 系统维护 | 1000（Kg→g） |
| 基本单位单价 | 采购单价 ÷ 系数 | 计算得出 | 24.3 IDR / g |
| 计价币种 | 默认 IDR | 系统 | IDR |

### 2.3 价格锁定机制（核心业务规则）

| 场景 | 锁定范围 | 备注 |
|---|---|---|
| **订单提交时** | 订单上冻结一批价格 | 即使目录价变化，已提交订单不受影响 |
| **收货时** | 如发现价格错误 | 加盟商 24h 内提出复核，总部财务纠正 |
| **对账时** | 实际结算价 = 收货确认价 | 不接受"下单后涨价"补差 |
| **促销期** | 订单提交时必须带 `promo_id` | 后台校验资质 + 适用范围 |

### 2.4 价格争议处理流程

```
加盟商提出价格异议
    │
    ▼
1. 加盟商在订单备注或对账单标记"价格争议"
    │
    ▼
2. 总部财务 48h 内核实（订单号 + 物料编码 + 报价单截图）
    │
    ▼
3a. 若总部失误（错价 / 漏改）→ 整单按正确价格冲账 + 道歉
3b. 若双方理解不一致 → 调取历史 3 单同类交易均价 + 提交区域经理裁决
    │
    ▼
4. 总部财务在系统注明最终价 + 加盟商书面确认（含飞书消息证据）
```

**MVP 局限**：暂不实现"系统自动定价校验"，所有价格争议走人工飞书沟通 + Excel 留痕。

## 3. 付款方式

### 3.1 付款方式分档

| 方式 | 定义 | 适用场景 | 信用要求 | MVP 状态 |
|---|---|---|---|---|
| **预付全款** | 下单时 100% 付款 | 新加盟商 / 一次性物料 | 无 | ✅ 支持 |
| **货到付款（COD）** | 收货时付现金 / 银行转账 | 印尼本地常用 | 视加盟商等级 | ✅ 支持 |
| **月结 N 天** | 收货后 N 天内付款 | 信用良好加盟商 | 月结 30 天内 | ⚠️ MVP 试点不启用（仅 1 家） |
| **银行转账** | 印尼银行（BCA / Mandiri / BRI） | 全场景 | 与付款方式搭配 | ✅ 推荐 |
| **现金 / 便利店付款** | Alfamart / Indomaret 代收 | COD 备份 | 仅小金额 | ⚠️ MVP 不推荐 |

### 3.2 MVP 默认付款方式

由于 1 家加盟商试点，且无历史信用数据，**MVP 默认采用「预付全款」+「货到付款（首选银行转账）」**。

- 订单金额 ≤ 5,000,000 IDR（约 2,500 元人民币）→ 允许货到付款
- 订单金额 > 5,000,000 IDR → 必须预付全款后发货
- 试点加盟商 MMY-BANTEN-SANGGIANG 起步按货到付款走 1 单验证流程

### 3.3 付款状态机

```
[待付款] → 加盟商已下单未付款
    │
    ├─→ 收到付款凭证 → [已付款待发货]   ✅ 正常路径
    │
    ├─→ 超过付款期限（48h） → [订单取消]  ⚠️ 自动取消
    │
    └─→ 加盟商主动取消 → [订单取消]

[已付款待发货] → 总部审核 + 备货
    │
    ├─→ 出库 → [已发货在途]
    │
    ├─→ 价格 / 库存问题 → [订单暂停]（人工介入）
    │
    └─→ 加盟商申请退款 → [退款处理中]

[已发货在途] → 物流运输中
    │
    ├─→ 签收 → [已收货待对账]
    │
    ├─→ 拒收 → [退货处理中]
    │
    ├─→ 短货 / 多货 → [部分收货待补] / [待处理多货]
    │
    └─→ 失联 / 丢件 → [物流异常]
```

**详细状态码（共 12 态）**：

| 状态码 | 中文 | 触发方 | 后续 |
|---|---|---|---|
| `PENDING_PAYMENT` | 待付款 | 系统 | 超 48h 自动取消 |
| `PAID_PENDING_SHIP` | 已付款待发货 | 系统 | 总部审核 |
| `SHIPPED_IN_TRANSIT` | 已发货在途 | 总部 | 物流更新 |
| `DELIVERED_PENDING_CHECK` | 已收货待核对 | 加盟商 / 系统 | 24h 内核对 |
| `PARTIALLY_RECEIVED` | 部分收货待补 | 加盟商 | 物流补发 / 对账 |
| `OVERAGE_PENDING` | 多货待处理 | 加盟商 | 总部回收 / 二次发货 |
| `RETURNED` | 已退货 | 加盟商 | 退款流程 |
| `RECONCILED` | 已对账 | 系统 / 总部财务 | 进入结算 |
| `INVOICED` | 已开票 | 总部财务 | 发票入账 |
| `CANCELLED` | 已取消 | 任一方 | 退款流程 |
| `ON_HOLD` | 订单暂停 | 系统 / 总部 | 人工介入 |
| `LOST_IN_TRANSIT` | 丢件 | 物流 | 索赔 / 重新发货 |

### 3.4 付款时限约定

| 方式 | 默认时限 | 备注 |
|---|---|---|
| 预付全款 | 下单后 48h 内付清 | 超时自动取消 |
| 货到付款 | 签收时同步付清（收款人 = 物流或加盟商现场付总部账户） | 物流代收风险由总部承担 |
| 月结 N 天 | 月结 30 天（即次月 30 日前付清） | 需总部财务审批额度 |

## 4. 信用政策

### 4.1 MVP 不启用正式信用额度

> **MVP 前提**：试点 1 家加盟商，且默认预付 / 货到付款，**不评估信用额度、不开设月结账期**。
>
> **信用政策整体设计先行写明**，规模化（≥ 5 家加盟商）前再启用。

### 4.2 信用评分卡（V2 启用）

| 维度 | 权重 | 计算方式 |
|---|---|---|
| 历史付款准时率 | 30% | 准时付款次数 / 总付款次数 |
| 历史退货率 | 15% | 退货金额 / 进货金额 |
| 合作时长 | 15% | 满 1 年 +5%，满 3 年 +10%，满 5 年 +15% |
| 月度进货稳定性 | 20% | 月度进货额 CV（变异系数）小者得分高 |
| 期末库存健康度 | 10% | 安全库存覆盖率 |
| 黑名单 / 法律纠纷 | 10% | 默认 100 分，发生扣分 |

**5 档信用等级**：

| 等级 | 信用分 | 月结额度 | 账期 |
|---|---|---|---|
| **AAA** | ≥ 90 | 50,000,000 IDR | 60 天 |
| **AA** | 80-89 | 30,000,000 IDR | 45 天 |
| **A** | 70-79 | 20,000,000 IDR | 30 天 |
| **B** | 60-69 | 10,000,000 IDR | 15 天 |
| **C** | < 60 | 0（仅预付 / COD） | 0 |

### 4.3 信用审批流程

```
加盟商申请月结
    │
    ▼
加盟商提交资料（营业执照 + 银行流水 + 历史交易）
    │
    ▼
总部财务初审（资料完整性 + 基础背景）
    │
    ▼
总部商务经理审核（业务规模 + 战略价值）
    │
    ▼
总部财务总监审批（信用额度）
    │
    ▼
系统写入「月结额度 + 账期」
    │
    ▼
加盟商确认接受条款（电子签章）→ 启用
```

### 4.4 信用降级触发

| 触发事件 | 影响 |
|---|---|
| 单次逾期付款 ≥ 7 天 | 等级降 1 档，30 天观察 |
| 单次逾期 ≥ 30 天 | 立即冻结月结，转预付 |
| 退货率季度均值 > 15% | 等级降 1 档 |
| 法律纠纷立案 | 立即冻结账户 |

## 5. 退款 / 取消

### 5.1 取消规则（订单尚未发货）

| 阶段 | 谁能取消 | 时限 | 是否退款 |
|---|---|---|---|
| 待付款（>0h） | 加盟商主动 | 随时 | 无需退款 |
| 已付款待发货（< 24h） | 加盟商主动 | 24h 内免手续费 | 全额退 |
| 已付款待发货（> 24h） | 加盟商主动 | 总部已备货可能扣 5-10% 手续费 | 部分退 |
| 已付款待发货 → 取消 | 总部主动（库存不足 / 价格错误） | 立刻 | 全额退 + 致歉 |

### 5.2 退款规则（订单已发货）

| 触发 | 责任方 | 退款比例 | 时限 |
|---|---|---|---|
| **加盟商拒收**（无理由） | 加盟商 | 退 50% + 物流费由加盟商承担 | 物流回货后 7 天 |
| **加盟商拒收**（质量问题） | 总部 | 全额退 + 物流费由总部承担 | 7 天 |
| **总部发错货** | 总部 | 全额退 + 补发正确货 + 物流费由总部承担 | 立即重发 |
| **总部少发**（短货） | 总部 | 短货金额退 + 补发或下次扣减 | 7 天 |
| **总部多发**（多货） | 总部 | 加盟商退回多发部分 + 物流费由总部承担 | 14 天 |
| **运输破损 / 丢件** | 物流 | 物流公司按申报价值赔偿（上限 50,000 IDR/件） | 14 天 |
| **加盟商超期收货** | 加盟商 | 货物归总部 + 已付款扣 30% | 物流回货后 |

### 5.3 退款状态机

```
[退款申请]
    │
    ├─→ 总部审核通过 → [退款处理中]
    │       │
    │       ├─→ 银行退款成功 → [退款完成]
    │       │
    │       └─→ 银行退款失败 → [人工处理]
    │
    └─→ 总部审核拒绝 → [已关闭]
            │
            └─→ 加盟商申诉 → [总部商务复审]
```

### 5.4 退款数据留痕

退款必须在订单中留下完整证据链：
- 退款原因 + 加盟商书面确认（含飞书消息截图）
- 总部审核人 + 审批时间
- 退款金额 + 退款时间 + 银行回单
- 关联原订单号

## 6. 部分收货 / 短货 / 多货

> 这是印尼物流常见的 3 个痛点，必须显式处理。

### 6.1 部分收货流程

```
[已发货在途] → 加盟商现场验收
    │
    ├─ 部分货物齐全 + 部分破损 → 加盟商签收并拍照标记
    │       │
    │       └─→ 在系统标记「部分收货」+ 列明已收 / 未收
    │               │
    │               ├─→ 总部决定补发 → [部分收货待补]
    │               │
    │               └─→ 总部决定退款 → 走退款流程
    │
    ├─ 全部破损 / 全部未到 → 加盟商拒收
    │       │
    │       └─→ 走退款流程（责任物流或总部）
    │
    └─ 全部齐全 → [已收货待核对]
```

### 6.2 短货处理（少发货）

| 步骤 | 时限 | 责任方 | 操作 |
|---|---|---|---|
| 1. 加盟商核对并拍照 | 收货时 0h | 加盟商 | 在订单上标记短货 |
| 2. 加盟商上传证据 | 收货时 24h 内 | 加盟商 | 拍照 + 视频（开箱） |
| 3. 总部核实 | 收到证据 24h 内 | 总部仓储 | 调出库单 + 重量复核 |
| 4a. 确认短货 | — | 总部 | 加盟商二选一：① 补发 ② 退款抵扣下次 |
| 4b. 加盟商误判 | — | 总部 | 沟通解释，关闭争议 |

**短货赔付标准**：
- 加盟商选择补发 → 运费由总部承担
- 加盟商选择退款 → 按订单单价 100% 退 + 30% 额外补偿（表达歉意）
- 短货率 > 5% → 触发物流商考核

### 6.3 多货处理（多发货）

| 场景 | 处理 |
|---|---|
| 加盟商主动报多货 | 退回多发部分（运费总部承担） + 总部仓储核实 |
| 加盟商未报多货 | 总部盘点发现 → 与加盟商沟通退回 |
| 加盟商拒绝退回 | 总部从下次订单中等额扣减 + 飞书书面确认 |

**多货处理原则**：多货必须 30 天内明确处理（退 / 扣减），不允许长期挂账。

### 6.4 验收争议窗口

| 类型 | 加盟商反馈窗口 | 总部响应窗口 |
|---|---|---|
| 数量短货 / 多货 | 收货后 24h | 收到报告后 24h |
| 包装破损 | 收货时现场 | 立即沟通 |
| 质量问题 | 收货后 7 天 | 收到报告后 48h |
| 实物与订单不符 | 收货后 7 天 | 收到报告后 24h |

**超出窗口后提出的争议默认不予受理**（除质量问题延保期之外）。

## 7. 对账流程

### 7.1 月度对账周期

```
自然月 → 次月 5 日前完成对账 → 次月 10 日前完成开票 → 次月 30 日前完成付款
```

| 节点 | 时限 | 责任方 |
|---|---|---|
| 月结订单关闭 | 月末最后 1 天 23:59 | 系统自动 |
| 加盟商核对 | 次月 1-3 日 | 加盟商 |
| 总部生成对账单 | 次月 4 日 | 总部系统 |
| 双方确认 | 次月 5 日 18:00 | 双方 |
| 总部开票 | 次月 6-10 日 | 总部财务 |
| 加盟商付款 | 次月 30 日前 | 加盟商财务 |
| 总部核销 | 收到款 3 日内 | 总部财务 |

### 7.2 对账单字段

| 字段 | 来源 | 备注 |
|---|---|---|
| 对账单号 | 系统生成 | `REC-YYYYMM-XXX` |
| 对账期间 | 自然月 | YYYY-MM |
| 加盟商 | 门店主数据 | MM000196 |
| 期初未付金额 | 上月结转 | — |
| 本月新增订单数 | 订单表 | — |
| 本月新增订单金额 | 订单表 | IDR |
| 本月已付款金额 | 付款流水 | IDR |
| 本月退款金额 | 退款流水 | IDR |
| 本月短货扣减 | 短货处理 | IDR |
| 本月多货扣减 | 多货处理 | IDR |
| 本月对账调整（人工） | 总部财务手动 | 需备注原因 |
| **期末应付金额** | 计算 | 期初 + 新增 − 已付 − 退款 − 扣减 ± 调整 |
| 双方确认状态 | 双方电子签 | — |
| 发票号 | 总部开票后 | — |

### 7.3 对账异常处理

| 异常 | 处理 |
|---|---|
| 加盟商未在 3 日内核对 | 系统自动确认 + 飞书催办 |
| 双方数据不一致 | 调取订单原始单据 + 物流签收记录，逐笔核对 |
| 单笔 > 100,000 IDR 差异 | 必须有书面争议记录 + 总部商务复核 |
| 月度总差异 > 5% | 触发财务专项审计 |

## 8. 发票流程

### 8.1 印尼发票类型

| 发票类型 | 适用 | 备注 |
|---|---|---|
| **Faktur Pajak**（税务发票） | B2B 交易 + PPN（增值税） | 强制 |
| **Nota Penjualan**（销售单） | 非税务凭证 | 加盟商内部记账用 |
| **Invoice**（普通发票） | 内部对账 | MVP 默认 |

> **V2 提示**：印尼 PPN 税率 11%（2026），MVP 暂不实现税务发票，由总部财务线下处理。
> **MVP 输出**：每次对账后生成「Invoice」PDF（含订单明细、金额、对账期间），作为加盟商记账凭证。

### 8.2 MVP 发票流程

```
[对账确认] → 次月 6-10 日
    │
    ▼
总部财务根据对账单生成 Invoice PDF
    │
    ▼
PDF 文件命名：INV-YYYYMM-MM000196.pdf
    │
    ▼
上传飞书云盘（加盟商专属文件夹）
    │
    ▼
飞书消息通知加盟商 + 附 PDF 链接
    │
    ▼
加盟商确认收到 → 对账关闭
```

### 8.3 发票字段

| 字段 | 来源 |
|---|---|
| Invoice 编号 | 系统生成（`INV-YYYYMM-XXX`） |
| 开票日期 | 系统当前日期 |
| 卖方 | MOMOYO INDONESIA 总部 |
| 买方 | MM000196 / MMY-BANTEN-SANGGIANG |
| 期间 | YYYY-MM（对账月） |
| 金额合计 | IDR |
| 订单明细 | 该月所有已对账订单 |
| 含税标识 | MVP 标 "Non-PPN" |
| 总财务签字 | 总部财务主管 |

### 8.4 发票争议

如加盟商在收到发票 7 天内提出异议（如金额不符 / 信息错误），走对账异常流程的同款流程，但必须重新开票，原发票标记作废。

## 9. 异常处理清单

| 异常类别 | 触发场景 | 第一响应方 | 时效 |
|---|---|---|---|
| **下单错误**（多下 / 错物料） | 加盟商已付款待发货 | 加盟商 / 总部 | 24h 内 |
| **付款失败** | 银行系统问题 | 加盟商 / 总部财务 | 立即 |
| **价格错误** | 总部报价失误 | 总部 | 24h 内纠正 |
| **库存不足** | 总部备货时 | 总部 | 立即通知加盟商 |
| **物流延期** | 超过预计到达日 24h | 物流 / 总部 | 24h 内查明 |
| **物流丢件** | 物流确认丢失 | 物流 | 立即启动索赔 |
| **货物破损** | 加盟商收货时 | 加盟商 / 总部 | 现场拍照 + 24h 内报告 |
| **加盟商拒收** | 无理由 / 质量问题 | 加盟商 | 现场决定 |
| **加盟商违约** | 拖欠 / 重复退货 | 总部 | 7 天催收 → 降级 |
| **发票丢失** | 加盟商本地丢失 | 总部 | 重新出 PDF |
