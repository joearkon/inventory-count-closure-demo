# 加盟商经营指标定义表 v1

> 维护方: 飞书/豆包工作侧
> 版本: v1 | 2026-09-17
> 配套: metric_dictionary.json v1 + threshold_table.json v1 + industry_baseline.md v1
> 适用: MOMOYO 印尼加盟商体系（MVP 首批）

---

## 文档说明

本文档定义 MOMOYO 加盟商经营 MVP 中**所有对外展示与计算口径**的指标。每个指标必须：

1. **公式明确** —— 不允许"行业通用"这类模糊定义
2. **数据来源明确** —— Base 表 / 计算服务 / 第三方
3. **缺数据时降级** —— 不能因为少数据就 panic，明确标注「不可用」
4. **动作链清晰** —— 加盟商看到 X 做什么，总部看到 X 做什么

每个指标附 **数据可信度** 字段（high / medium / low）：
- **high**：Base 表数据完整 + 公式无歧义 + 历史 ≥ 7 日
- **medium**：部分数据缺失 / 公式依赖实时同步 / 历史 < 7 日
- **low**：仅快照数据 / 完全依赖手动录入 / 无历史

## 一、销售类（Sales）— 10 个指标

### S-01 日营业额

| 字段 | 内容 |
|---|---|
| 公式 | Σ(订单金额)，按门店 + 日期 聚合 |
| 业务意义 | 单店单日销售总额；反映门店当日经营规模 |
| 数据来源 | 门店销售明细（`tbly9ewKpWTpeQzC`），订单金额字段 |
| 适用门店 | 所有加盟门店 |
| 统计周期 | 日（按门店当地时间 00:00 切日） |
| 缺数据处理 | 当日无销售 → 标记"停业 / 异常"，加盟商自查 |
| 加盟商动作 | 每日查看 + 周累计对比 |
| 总部动作 | 区域排名 + 异常门店定位 |
| 可信度 | high（POS 自动收银，订单数据完整）|

### S-02 日销量（按 SKU）

| 字段 | 内容 |
|---|---|
| 公式 | Σ(销售数量)，按门店 + 日期 + SKU 聚合 |
| 业务意义 | 单 SKU 单日销量；用于 SKU 级别分析与补货决策 |
| 数据来源 | 门店销售明细 |
| 适用门店 | 所有加盟门店 |
| 统计周期 | 日 / 周 / 月 |
| 缺数据处理 | 当日无销量 → 标记"未上架 / 滞销"，纳入 SKU 淘汰评估 |
| 加盟商动作 | 滞销 SKU 优先促销 / 下架 |
| 总部动作 | SKU 区域热度分析 + 配方调整建议 |
| 可信度 | high |

### S-03 月营业额

| 字段 | 内容 |
|---|---|
| 公式 | Σ(日营业额)，自然月 |
| 业务意义 | 单店单月销售总额；用于月度报表与加盟商评级 |
| 数据来源 | 日营业额聚合 |
| 统计周期 | 自然月（1 日-末日） |
| 缺数据处理 | 月内缺失 ≥ 3 日 → 标记"数据不完整"，需补录 |
| 加盟商动作 | 月底自评对比 |
| 总部动作 | 月度加盟商评级 + 信用评估 |
| 可信度 | high |

### S-04 月销量

| 字段 | 内容 |
|---|---|
| 公式 | Σ(日销量)，自然月 |
| 业务意义 | 单店单月销量（杯数）；用于运营节奏感 |

| 总部动作 | 同 S-03 |
| 可信度 | high |

### S-05 客单价

| 字段 | 内容 |
|---|---|
| 公式 | 日营业额 / 日订单数 |

| 可信度 | high |

### S-06 日订单数

|---|---|
| 公式 | COUNT(DISTINCT 订单 ID)，按门店 + 日期 |

### S-07 同期对比（周环比）

|---|---|

| 总部动作 | 区域周环比排名 |
| 可信度 | medium（依赖历史 ≥ 7 日）|

### S-08 同期对比（月环比）

|---|---|

## 三、库存差异类（Inventory Variance）— 8 个指标

### I-01 期末库存

| 字段 | 内容 |
| |---|
| 公式 | 期初 + 入库 - 消耗 - 报损，按门店 + 物料 + 日期 |
| 业务意义 | 当日结束时某物料的理论库存量 |
| 数据来源 | 门店库存台账（`tblGDep7xILyvVgy`）|
| 适用门店 + 物料 | 所有 |
| 统计周期 | 日切 |
| 缺数据处理 | 期初缺失 → 标记"无基线"，期末不可计算 |
| 加盟商动作 | 低于安全库存 → 补货 |
| 总部动作 | 区域物料紧急度排序 |
| 可信度 | high（依赖台账更新及时性）|

### I-02 理论库存 - 实盘差异

| 字段 | 内容 |
| |---|
| 公式 | 期末库存 - 实盘数量 |
| 业务意义 | 理论与实盘的绝对差异 |
| 数据来源 | 期末库存 + 盘点数据 |
| 统计周期 | 每次盘点 |
| 缺数据处理 | 无盘点 → 差异不可计算，触发提醒 |
| 加盟商动作 | 差异 > 阈值 → 排查盘点误差 / 损耗 |
| 总部动作 | 异常门店派人现场盘点 |
| 可信度 | medium |

### I-03 差异率

| 字段 | 内容 |
| |---|
| 公式 | |理论库存 - 实盘| / 实盘 |
| 业务意义 | 差异占实盘的比例；行业基准 1-5%（按物料）|
| 数据来源 | 理论库存 + 实盘 |
| 统计周期 | 每次盘点 |
| 缺数据处理 | 同 I-02 |
| 加盟商动作 | 差异率 > 物料阈值 → 复核 |
| 总部动作 | 督导派单 |
| 可信度 | medium |

| 统计周期 | 日 / 周 |
| 缺数据处理 | — |
| 加盟商动作 | 必查流程漏洞 |
| 总部动作 | 紧急介入 |
| 可信度 | high |

### I-05 盘点缺失天数

| 字段 | 内容 |
| |---|
| 公式 | COUNT(连续无盘点)，按门店 |
| 业务意义 | 门店未做盘点的连续天数 |
| 数据来源 | 盘点记录 |
| 统计周期 | 滚动 |
| 缺数据处理 | — |

| 总部动作 | 缺失 ≥ 7 日 → 派人现场协助 |
| 可信度 | high |

### I-06 盘点异常次数

| |---|

| 总部动作 | 督导派单 |
| 可信度 | high |

### I-07 盘点异常率

| 字段 | 内容 |
| |---|
| 公式 | 盘点异常次数 / 盘点总次数 |

| 统计周期 | 周 / 月 |

| 总部动作 | 异常率持续 > 30% → 督导长期介入 |

### I-08 盘点完成率

| 字段 | 内容 |
| |---|
| 公式 | 已盘点次数 / 应盘点次数 |

## 四、缺货风险类（Stockout Risk）— 5 个指标

| 总部动作 | 区域覆盖率排名 |
| 可信度 | high |

| 总部动作 | 预警清单 + 紧急调拨 |

### R-03 缺货次数

| 字段 | 内容 |
| |---|

| 总部动作 | 缺货物料调拨 |
| 可信度 | high |

### R-04 缺货 SKU 数

| 总部动作 | 区域缺货分布 |
| 可信度 | high |

### R-05 缺货损失估算

| 字段 | 内容 |
| |---|

| 总部动作 | 月度缺货损失排行榜 |
| 可信度 | low（依赖数据完整度）|
